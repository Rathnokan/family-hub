DECISIONS IN THIS PASS
Points are not global — Rewards owns them; other modules publish credits. Rewards off = points gone, tasks intact.

Allowance, pts/$ and ranks → Rewards · Economy, not System.

Penalties & streaks stayed in Chores — task rules that cost points.

Themes → System · Family, on the person record.

Warranties & contracts are not funds — they're per-asset coverage and recurring vendor spend, compared against the fund in 2d.

Escalation is one System value with a bindable source, not a number typed into each asset.
