On theme backgrounds

How each style sits on the more stylised themes. Line icons take the theme ink color; emoji are always full-color (this is the main aesthetic trade-off).

Option 3 — redraw the line icons (illustrative)

Filled instead of hollow. Clearer than today and keeps a single-color, on-theme look — but every one of the ~68 icons has to be redrawn by hand, and a filled outline still won't read as fast as a colored emoji for a pre-reader.

My recommendation: Emoji — native. It's the clearest for the kids, costs nothing in bundle size, and keeps every chore's existing icon so nothing needs re-picking. If the slight device-to-device glyph difference bothers you, the bundled set fixes that for ~100 KB.
